# The Museum Has Forgotten You

A playable, original browser-based retro museum horror game.

## Play

GitHub Pages: https://24120921sjlee.github.io/museumhasforgotten/

## Controls

- Choose one of two actions in each exhibit.
- One choice advances; the other leads to Game Over.
- Reach Exhibit 20 for the Good End.

The game uses a 320 × 240 internal canvas with nearest-neighbor scaling, a muted museum palette, and 20 original scenes.
